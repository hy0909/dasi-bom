## 지금 가짜로 돌아가는 것

데모에서는 잘 돌아가지만 실제로는 아무것도 저장되지 않는 부분입니다.

| 무엇 | 지금 | 실제로 필요한 것 |
| --- | --- | --- |
| 로그인 | localStorage에 세션만 씀 | 구글·카카오 OAuth |
| 앨범·사진·글 | 프론트 상수와 메모리 | DB와 조회·저장 API |
| 사진 업로드 | 브라우저 미리보기 | 스토리지 업로드, 촬영 시각 추출 |
| 목소리 | 녹음만 되고 사라짐 | 오디오 파일 업로드와 재생 URL |
| AI 질문·글 | 고정 문구 | 사진 기반 질문 생성, 답변 요약 |
| 알림 | 고정 2건 | 이벤트 발생과 읽음 처리 |
| 초대 링크 만료 | 브라우저 시각으로 계산 | 서버 시각과 만료 검증 |

## 서버 붙이는 순서 제안

앞 단계가 되면 뒤 단계가 자연스럽게 풀립니다.

| 순서 | 묶음 | 왜 먼저인가 |
| --- | --- | --- |
| 1 | 로그인, 내 정보 | 사용자가 있어야 앨범 주인이 정해진다 |
| 2 | 앨범 CRUD, 내 앨범 목록 | 화면 대부분이 이 데이터를 본다 |
| 3 | 사진 업로드, 사진 목록 | 기록·목소리·연대표가 전부 사진에 붙는다 |
| 4 | 초대 링크 발급·합류 | 구성원이 생겨야 협업 흐름이 돈다 |
| 5 | 답변 저장, 목소리 업로드 | 사진과 구성원이 있어야 의미가 생긴다 |
| 6 | AI 질문·글 생성 | 답변이 쌓인 뒤에 붙이면 된다 |
| 7 | 알림 | 나머지가 다 돌아간 뒤 마지막 |
