# 다시, 봄 — UX 플로우 기획서

> UX 플로우 다이어그램 생성용 입력 문서. 화면 단위 ID, 분기 조건(Y/N), 역할, 상태, 예외 경로를 그대로 노드/엣지로 옮길 수 있게 정리했습니다.
> 기준 코드: `src/App.tsx`, `src/screens/*` (2026-09-14)

## 1. 역할 (Role)

| 역할 | 설명 | 인증 |
|---|---|---|
| `HOST` | 기록 소유자(하연). 기록 생성·편집·초대 권한 | 로그인 상태로 가정 (프로토타입은 항상 로그인) |
| `GUEST` | 초대 링크로 들어온 가족. 답변만 가능 | 회원가입 없음. 닉네임만 `localStorage.dasiBomGuest` 에 저장 |

## 2. 전역 상태 (State)

| 상태 키 | 값 | 보관 위치 |
|---|---|---|
| `screen` | 14개 화면 ID 중 하나 | React state (`src/App.tsx`) |
| `title` | 기록 제목. 기본 "2023년 유럽여행" | React state |
| `ready` | 초기 부팅 완료 여부. `false` 동안 부팅 화면 | React state |
| `dasiBomGuest` | 게스트 닉네임 | `localStorage` |
| `?invite=EU23` | 초대 코드 | URL 쿼리스트링 |

## 3. 화면 목록 (Node)

| ID | 이름 | 역할 | 비고 |
|---|---|---|---|
| `S0_BOOT` | 부팅 | 공통 | `ready=false` 동안 표시 |
| `S1_HOME` | 홈 | HOST | 하단 네비 노출 |
| `S2_CREATE` | 새 기록 만들기 | HOST | 폼 |
| `S3_DETAIL` | 기록 상세 | HOST | 탭 4개 |
| `S4_INTERVIEW` | 사진 이야기 남기기 | HOST | AI 질문 3단계 |
| `S5_VOICE` | 목소리로 답하기 | HOST | 실제 마이크 녹음 |
| `S6_STORY` | 사진 이야기 | HOST | 보기/수정 모드 |
| `S7_INVITE` | 가족 초대하기 | HOST | 링크 공유 |
| `S8_UPLOAD` | 사진 추가하기 | HOST | 다중 파일 |
| `S9_NOTICES` | 알림 | HOST | 리스트 |
| `S10_PROFILE` | 내 설정 | HOST | 토글·로그아웃 |
| `G1_WELCOME` | 초대 랜딩 | GUEST | 참여 안내 |
| `G2_INFO` | 참여자 정보 | GUEST | 닉네임·관계·동의 |
| `G3_ANSWER` | 이야기 남기기 | GUEST | 사진 3장 순차 |
| `G4_DONE` | 참여 완료 | GUEST | 통계 요약 |

## 4. 진입 분기 (Entry)

```
앱 로드 → S0_BOOT
  └ URL 에 ?invite=EU23 가 있는가?
      ├ Y → G1_WELCOME   (게스트 플로우)
      └ N → S1_HOME      (호스트 플로우)
```

## 5. 호스트 플로우

### 5.1 S1_HOME — 홈

| 트리거 | 분기 | 결과 |
|---|---|---|
| 새 기록 만들기 카드 | — | → `S2_CREATE` |
| 기록 카드 본문 클릭 | — | → `S3_DETAIL` |
| 기록 카드 더보기 `···` | 이름 수정 | 토스트 (프로토타입) |
| | 공유 | → `S7_INVITE` |
| | 삭제 | 토스트 (확인 절차 미구현) |
| 정렬 버튼 | 현재 최근순인가? | Y → 오래된 순 / N → 최근 수정순. 둘 다 토스트 |
| 하단 네비 | 기록 / 초대 / 알림 / 나 | `S1_HOME` / `S7_INVITE` / `S9_NOTICES` / `S10_PROFILE` |
| 하단 네비 중앙 `＋` | — | → `S2_CREATE` |

### 5.2 S2_CREATE — 새 기록 만들기

```
제목 입력
  └ 제목이 비어 있는가?
      ├ Y → [기록 만들기] 버튼 비활성 (제출 불가)
      └ N → 제출 가능

대표 사진 선택
  └ 선택한 파일이 이미지인가?
      ├ Y → 미리보기 표시
      └ N → 토스트 "이미지 파일만 선택해주세요" (파일 무시, 화면 유지)

제출 → 버튼 "기록을 만들고 있어요…" → 0.5초 후 S3_DETAIL
```

### 5.3 S3_DETAIL — 기록 상세

진행률 70%, 남은 답변 1건을 요약 카드로 안내.

| 탭 | 트리거 | 분기 | 결과 |
|---|---|---|---|
| 사진 | 사진 타일 | 첫 번째 사진(이야기 완성)인가? | Y → `S6_STORY` / N → `S4_INTERVIEW` |
| 사진 | 정렬 버튼 | 촬영일순 ↔ 진행 상태순 | 목록 재정렬 + 토스트 |
| 목소리 | 재생 버튼 | 이미 재생 중인가? | Y → 정지 / N → 재생. 둘 다 토스트 |
| 이야기 | 이야기 카드 | — | → `S6_STORY` |
| 연대표 | 타임라인 항목 | 첫 번째 항목인가? | Y → `S6_STORY` / N → `S4_INTERVIEW` |

| 그 외 트리거 | 결과 |
|---|---|
| 요약 카드 [이어서 이야기 남기기] | → `S4_INTERVIEW` |
| 상단 [가족 초대] | → `S7_INVITE` |
| 플로팅 [＋ 사진 추가] | → `S8_UPLOAD` |
| 뒤로가기 | → `S1_HOME` |

### 5.4 S4_INTERVIEW — 사진 이야기 남기기

상태: `question` 0→1→2 (3단계), `textMode` (음성/글 선택).

```
질문 n 표시 (n>0 이면 이전 답변 인용 노출)
  ├ [목소리로 답하기] → S5_VOICE
  ├ [글로 답하기] → textarea 모드 (최대 500자)
  │     └ 답변이 비어 있는가?
  │         ├ Y → 제출 버튼 비활성
  │         └ N → 제출
  │              └ 마지막 질문(n=2)인가?
  │                  ├ Y → 토스트 "사진 이야기가 완성됐어요" → S6_STORY
  │                  └ N → 다음 질문으로, 답변 초기화 + 토스트
  └ [이 질문은 건너뛸게요]
        └ 마지막 질문인가?  Y → S3_DETAIL / N → 다음 질문

상단 [나가기] / 뒤로가기 → S3_DETAIL
```

### 5.5 S5_VOICE — 목소리로 답하기 (예외 경로 포함)

```
[● 녹음] 클릭 → navigator.mediaDevices.getUserMedia({audio:true})
  ├ 권한 거부 / 장치 없음 (예외)
  │     → 토스트 "마이크 권한을 허용하거나 글로 답해주세요"
  │     → 화면 유지 (대기 상태로 복귀)
  └ 권한 허용
        → 녹음 중: 파형 애니메이션 + 타이머 mm:ss (최대 5분 안내)
        → [■ 정지] → Blob 생성 → 미리듣기 플레이어 노출
             ├ [다시 녹음] → 녹음본 폐기(ObjectURL revoke), 타이머 0으로
             └ [이 목소리 남기기] → 토스트 저장 완료 → S6_STORY

[글로 답하기] (대기 상태에서만 노출) → S4_INTERVIEW
뒤로가기 → S4_INTERVIEW · 화면 이탈 시 마이크 트랙 정리
```

### 5.6 S6_STORY — 사진 이야기

| 모드 | 트리거 | 결과 |
|---|---|---|
| 보기 | 원본 목소리 카드 | 재생 ↔ 정지 토글 + 토스트 |
| 보기 | 상단 [수정] | 수정 모드로 전환 |
| 수정 | 문체 선택 | 따뜻하게 / 담백하게 / 회고록처럼 중 택1 |
| 수정 | [이야기 저장하기] | 보기 모드 복귀 + 토스트 "{문체} 스타일로 이야기를 저장했어요" |
| 수정 | 상단 [취소] | 편집 내용 버리고 보기 모드 |
| 공통 | 뒤로가기 | → `S3_DETAIL` |

### 5.7 S7_INVITE — 가족 초대하기

```
진입 시 초대 링크 생성: {origin}{pathname}?invite=EU23

[복사]
  └ navigator.clipboard 사용 가능한가?
      ├ Y → 클립보드 복사
      └ N → textarea + execCommand('copy') 폴백
  → 토스트 "실제 가족 참여 링크를 복사했어요"

[공유하기]
  └ navigator.share 지원하는가?
      ├ Y → OS 공유 시트  (사용자가 취소하면 아무 동작 없음)
      └ N → 복사 폴백

[문자로 보내기] → sms: 스킴으로 기본 메시지 앱 호출
[초대 화면 체험] → G1_WELCOME (호스트가 게스트 뷰 미리보기)

참여자 목록: 엄마(완료) / 아버지(참여 중) / 동생 민준(초대됨) → 행 클릭 시 상태 토스트
뒤로가기 → S3_DETAIL
```

### 5.8 S8_UPLOAD — 사진 추가하기

```
파일 선택 (다중)
  └ 이미지 파일만 통과, 그 외는 조용히 제외
선택 목록
  ├ 각 항목 [×] → 목록에서 제거
  └ 선택 0장인가?
      ├ Y → [사진 업로드 완료] 비활성
      └ N → 클릭 시 토스트 "{n}장의 사진을 추가했어요" → S3_DETAIL
```

### 5.9 S9_NOTICES / S10_PROFILE

| 화면 | 트리거 | 결과 |
|---|---|---|
| `S9_NOTICES` | "엄마가 새 목소리를 남겼어요" | → `S3_DETAIL` |
| `S9_NOTICES` | "새로운 사진 이야기가 완성됐어요" | → `S6_STORY` |
| `S10_PROFILE` | 가족 답변 알림 스위치 | 켜짐 ↔ 꺼짐 |
| `S10_PROFILE` | 공유 링크 관리 / 이용약관 | 토스트 (프로토타입) |
| `S10_PROFILE` | 로그아웃 | `localStorage.dasiBomGuest` 삭제 → 토스트 → `S1_HOME` |

## 6. 게스트 플로우

### 6.1 G1_WELCOME — 초대 랜딩

```
초대자·기록 제목·참여 3단계 안내 노출
  ├ [이 기록에 참여하기] → G2_INFO
  └ [지금은 참여하지 않을게요]
        → URL 쿼리스트링 제거(history.replaceState) → S1_HOME
```

### 6.2 G2_INFO — 참여자 정보

```
닉네임(필수) · 가족 관계 선택(필수) · 처리 동의 체크(필수)
제출
  └ 셋 중 하나라도 비었는가?
      ├ Y → 토스트 "이름·관계·동의를 모두 확인해주세요" (화면 유지)
      └ N → localStorage.dasiBomGuest = 닉네임 → G3_ANSWER

뒤로가기 → G1_WELCOME
```

### 6.3 G3_ANSWER — 이야기 남기기 (사진 3장 순차)

```
사진 n (0,1,2) + AI 질문 표시, 진행률 n+1 / 3
  ├ 답변이 비어 있는가?
  │   ├ Y → 제출 버튼 비활성
  │   └ N → 제출
  │        └ 마지막 사진(n=2)인가?
  │            ├ Y → G4_DONE
  │            └ N → 다음 사진, 입력 초기화 + 토스트 "답변을 저장했어요"
  └ [이 사진은 건너뛸게요]
        └ 마지막 사진인가?  Y → G4_DONE / N → 다음 사진

뒤로가기 → G2_INFO
```

### 6.4 G4_DONE — 참여 완료

```
"{닉네임}님의 이야기" + 답변한 사진 3장 / 텍스트 답변 2개 요약
  ├ [답변 다시 보기] → G3_ANSWER (처음 사진부터)
  └ [참여 마치기] → URL 쿼리스트링 제거 → S1_HOME
```

## 8. 미구현 / 확인 필요

- 기록 삭제에 확인 모달이 없습니다. 현재는 토스트만 표시합니다.
- 초대 링크 만료(2026-09-28) 후 접근 시 동작이 정의돼 있지 않습니다.
- AI 정리 실패, 업로드 실패 등 서버 오류 경로가 없습니다. 프론트 프로토타입 범위 밖입니다.
- 게스트가 목소리로 답하는 경로는 안내 문구에만 있고 화면은 텍스트 입력만 제공합니다.
