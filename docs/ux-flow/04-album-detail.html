· 구성원 상태 뱃지
· 재초대 버튼 없음

· "n장 중 m장 남았어요"
· 행 탭 → 사진 기록 남기기
· 뒤로가기 → 상세
버튼 숨김
· [이어서 기록 남기기] 없음
선택 사진 미전달
앱 상태에 앨범 id만 있고 사진 id가 없다.
어느 사진을 눌러도 기록 · 목소리는 첫 '기록 중' 사진, 글은 글 있는 첫 사진을 연다.
서버 연동 전 FE 라우팅 상태 추가가 필요하다.
