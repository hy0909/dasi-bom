# 다시, 봄 — 기능 명세

프로토타입에 실제로 들어 있는 화면과 동작만 적었습니다. 화면을 옆에 띄워 놓고 표를 따라가면 됩니다.
"서버 몫" 칸은 확정 API가 아니라, 그 기능이 진짜로 돌아가려면 서버가 뭘 해줘야 하는지 적은 것입니다. 경로와 바디는 백엔드에서 정하시면 됩니다.

기준 코드 `4253da4` (2026-09-16). 배포본 https://hy0909.github.io/dasi-bom/ 도 같은 빌드입니다.

- 실행: `npm run dev` → 터미널에 뜨는 주소 (기본 5173, `PORT=` 로 바꿀 수 있음)
- 초대 링크 테스트: 주소 뒤에 `?invite=SUMMER` (유효) / `?invite=JEJU` (만료) / `?invite=SEA` (아직 내 앨범이 아닌 앨범)

## 용어

| 용어 | 뜻 |
| --- | --- |
| 앨범 | 여행이나 시기 하나. 사진·목소리·글이 여기에 묶인다 |
| 구성원 | 앨범에 참여 중인 사람. 만든 사람(owner)과 링크로 들어온 사람(member)을 구분한다. 이 구분이 쓰이는 곳은 홈의 분류 필터, 삭제 메뉴 노출, 상세 명단 모달의 내 줄 문구 세 곳 |
| 기록 | 가족이 사진에 남기는 목소리·글, 그리고 AI가 그걸 모아 정리한 글. 화면에서는 '답변'이라는 말을 쓰지 않는다 |
| 기록 상태 | 사진 한 장 단위. `기록 중` / `기록 완료` 둘뿐. 앨범 자체에는 상태가 없다 |
| 초대 링크 | 앨범마다 코드 하나. 발급일부터 7일 |
| 게스트 | 가입 없이 링크로 들어와 글로만 기록을 남기는 사람 |

## 기록 (사진·목소리·글)

| C-01 | 사진 추가 | 사진 추가하기 | 여러 장 고르고 빼기 → [사진 n장 추가하고 기록 시작] | 데스크톱 크로미움은 폴더 선택창(File System Access, 다운로드 폴더부터), 그 외는 파일 input. 이미지 타입이면 전부 통과(안내 문구는 JPG·PNG·WebP). 촬영 시각은 EXIF가 아니라 파일 수정 시각, 장소는 "위치 없음" 고정. 고른 순서와 무관하게 촬영순 정렬. 완료하면 앨범에 실제로 들어가고(메모리) 곧바로 기록 화면으로 넘어간다. 새로고침하면 사라진다 | 업로드, EXIF에서 촬영 시각·위치 추출, 사진 레코드 생성 |
| C-02 | 기록할 사진 목록 | 이어서 기록 남기기 | 남은 사진 훑고 하나 선택 | 기록 중인 사진만. "n장 중 m장 남았어요". 어떤 걸 눌러도 기록 화면은 첫 번째 기록 중 사진을 연다 — 선택값이 넘어가지 않는다 | 상태별 사진 조회 |

| C-05 | 글 확인과 수정 | 사진 기록 | 글 읽기, 문체 고르기, 제목·본문 고쳐 저장, 좌우로 사진 넘기기 | 본문은 데이터에 적어둔 글. 문체 3종(따뜻하게·담백하게·회고록처럼) 버튼은 저장 토스트 문구만 바꾼다. 제목·본문 입력은 값이 잡히지 않는 비제어 필드여서 저장해도 아무 데도 반영되지 않는다. 항상 첫 사진부터 시작. 태그·인용 문구 고정 | 글 생성(문체 파라미터), 제목·본문 저장 |
| C-06 | 기록 분류 보기 | 상세 → 기록 탭 | 사진 / 목소리 / 글 / 연대표 | 사진·글 탭은 전체 / 기록 중 / 기록 완료 필터. 사진 타일은 기록 완료면 글 화면, 아니면 기록 화면. 글 탭 카드는 글이 있으면 [글 수정], 없으면 [기록 이어가기]. 목소리 탭의 연필은 목소리로 답하기로 | B-06 응답 재사용 |

## 초대와 참여

| D-01 | 참여 링크 | 초대 | 링크 복사 / 공유 | `주소?invite=코드`. 앨범마다 코드가 다르고 발급일 + 7일까지. 만료 계산은 브라우저 시각. "n일 남았어요" / "오늘이 마지막 날이에요". 복사는 클립보드 API, 안 되면 execCommand. 공유는 OS 공유 시트, 없으면 복사로 | 링크·만료 시각 조회. 만료 판정은 서버 시각으로 |
| D-02 | 링크 새로 만들기 | 초대 | 만료됐을 때 [링크 새로 만들기] | 코드와 발급 시각이 바뀐다. 이미 들어온 구성원은 그대로. 새로고침하면 새 코드는 인식되지 않는다(부팅 때 시드 상수를 본다) | 재발급 |
| D-03 | 초대할 앨범 고르기 | 초대 (탭 진입) | 세로 리스트에서 앨범 선택 | 하단 탭이나 홈 `···`→공유로 들어왔고 앨범이 2개 이상일 때. 커버·제목·시작일·사진 수 + 라디오. 기본값은 마지막으로 열었던 앨범 | 참여 앨범 목록 |
| D-04 | 구성원 목록 | 초대 | 상태 보고 다시 초대 | 참여 중 / 초대됨 / 다시 초대. [다시 초대]는 토스트만. "기록 n개" 문구는 고정값. 인원수에 나는 안 들어간다. 상세 모달은 나를 더해 세서, 명단에 내 이름이 없는 시드 앨범에서는 1 크다 | 구성원·기록 수 조회, 재초대 발송 |
| D-05 | 만들고 바로 초대 | 앨범 생성 직후 | 링크 공유 → [앨범에 사진 추가] 또는 오른쪽 위 ✕ | "앨범을 만들었어요" 화면. 뒤로가기·하단 탭은 없고 나가는 길은 둘 — ✕(닫기)는 앨범 홈으로, [앨범에 사진 추가]는 사진 추가로. 예전의 '앨범 보러 가기'는 없다 | - |
| D-06 | 앨범에서 초대 | 상세 → 초대 | 그 앨범 링크 바로 보기 | 앨범 고정(선택기 없음), 상단 뒤로가기, 하단 탭 없이 화면을 꽉 채운다 | - |
| D-07 | 회원이 링크로 진입 | `?invite=코드` | 자동 합류 | 아는 코드 + 미만료 + 가입 완료면 구성원에 추가(같은 이름이 있으면 무시)하고 내 앨범에 '초대받은'으로 들어간 뒤 상세로. 주소에서 코드는 지운다 | 코드로 앨범 조회, 합류(중복·만료 검증) |
| D-08 | 비회원이 링크로 진입 | 게스트 참여 | 닉네임·관계·동의 → 사진마다 글 → 완료 | 랜딩의 "하연님이 초대했어요"는 고정 문구. 관계는 어머니 / 아버지 / 형제·자매 / 친척. 사진 수는 그 앨범 사진 수만큼, 진행 바 "사진 n / N". 글만 가능(목소리 없음). 저장되는 건 localStorage의 닉네임뿐이고 답은 남지 않는다. 완료 화면의 "3장 / 2개"는 고정값. [참여 마치기]는 로그인 없이 홈으로 간다 | 게스트 등록, 답 저장, 완료 요약, 초대자 이름 |
| D-09 | 만료된 링크 | 게스트 | 안내 보고 닫기 | 회원·비회원 모두 "링크가 만료됐어요" + [닫기] → 홈 | - |

모르는 코드(`?invite=XXXX`)는 조용히 무시하고 평소처럼 켜집니다. 주소에 코드만 남습니다.

| E-01 | 알림 목록 | 알림 | 항목 누르면 앨범 상세 | 고정 2건(새 목소리 · 앨범 완성), 하단 탭 배지도 2 고정. 누르면 마지막으로 연 앨범이 열린다 — 알림과 앨범이 연결돼 있지 않다. 읽음 처리 없음 | 알림 목록·미읽음 수·읽음 처리, 알림→앨범 id |
| E-02 | 기록 알림 스위치 | 내 설정 | 켜고 끄기 | 화면 안에서만 바뀌고 저장되지 않는다. 다른 탭 갔다 오면 켜짐으로 돌아온다 | 설정 저장 |
| E-03 | 이용약관 | 내 설정 | 행 누름 | 토스트만 | 약관 문서 |

내 설정에 있던 '공유 링크 관리' 행은 뺐습니다. 필요해지면 그때 다시 정의합니다.

## 앱이 켜질 때

```
주소에 ?invite=코드 가 있고, 시드 앨범(EU23 · JEJU · SUMMER · SEA) 코드인가?
├ 예 → 발급 후 7일이 지났나?
│      ├ 예 → 만료 안내 (회원·비회원 공통)
│      └ 아니오 → 가입을 마친 세션이 있나?
│             ├ 예 → 앨범에 합류 → 주소에서 코드 제거 → 앨범 상세
│             └ 아니오 → 게스트 랜딩
└ 아니오 (코드 없음 / 모르는 코드) → 세션이 있나?
       ├ 없음 → 로그인
       ├ 있음, 가입 완료 → 홈
       └ 있음, 가입 중단 → 약관(1/2)부터 다시
```

## 화면 이동

| 출발 | 도착 | 조건 |
| --- | --- | --- |
| 로그인 | 약관 → 프로필 → 홈 | 신규 계정 |
| 로그인 | 홈 | 가입을 마친 계정 |
| 로그인 | 게스트 랜딩 | [초대 링크로 참여하기] — 앨범은 마지막으로 연 앨범(처음 켰을 땐 시드 첫 앨범) |
| 홈 | 앨범 상세 | 카드 |
| 홈 `···` | 앨범 정보 / 초대 | 정보 수정 / 공유 |
| 새 앨범 만들기 | 초대 (생성 직후) | 자동 |
| 초대 (생성 직후) | 사진 추가 | [앨범에 사진 추가] |
| 초대 (생성 직후) | 홈 | 오른쪽 위 ✕ (닫기) |
| 사진 추가 | 사진 기록 남기기 | 추가 완료 시 자동 |
| 앨범 상세 | 기록할 사진 | [이어서 기록 남기기] |
| 상세 · 기록할 사진 · 연대표 | 사진 기록 남기기 | 기록 중 사진 |
| 상세 · 글 탭 | 사진 기록 (글) | 기록 완료 사진 |
| 사진 기록 남기기 | 목소리로 답하기 | [목소리로 답하기] |
| 목소리 / 3번째 답 | 사진 기록 (글) | 남기기 / 제출 |
| 앨범 상세 | 초대 (앨범 고정) | [초대] |
| 초대 링크 | 상세 / 게스트 / 만료 안내 | 위 분기 |

뒤로가기는 두 가지입니다. 앨범 정보·기록할 사진·프로필 수정·초대(상세에서 들어온 경우)는 실제로 거쳐온 화면으로 돌아가고, 나머지는 목적지가 고정입니다(상세→홈, 기록·글→상세, 목소리→기록, 사진 추가→상세). 하단 탭 4개(홈·초대·알림·나) 사이를 오갈 때는 기록을 쌓지 않습니다. 홈 `···`→공유도 탭 사이 이동이라, 그렇게 연 초대 화면에는 뒤로가기가 없고 하단 탭이 그대로 보입니다.

## 데이터가 어디에 있나

| 데이터 | 지금 | 새로고침하면 |
| --- | --- | --- |

| 구성원 | 메모리 스토어 | 시드로 |
| 사진 · 목소리 · 글 | 메모리 스토어. 올린 사진은 blob URL | 시드로 |
| 알림 | JSX에 고정 | - |

시드 앨범은 넷입니다. 유럽여행(EU23)·할머니와 보낸 여름(SUMMER)은 내가 만든 앨범, 제주(JEJU)는 초대받은 앨범, 바닷가(SEA)는 링크를 타야 들어옵니다. 제주 링크는 발급 23일 전으로 잡혀 있어 처음부터 만료 상태입니다.
