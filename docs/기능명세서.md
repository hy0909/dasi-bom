# 다시, 봄 — 기능 명세

프로토타입에 실제로 구현돼 있는 화면과 동작만 적었습니다. 화면을 띄워 놓고 표를 따라가면 됩니다.
API 칸은 확정된 스펙이 아니라 "이 기능에는 이런 호출이 하나 필요하다" 정도의 제안입니다. 경로와 바디는 백엔드에서 정하시면 됩니다.

실행: `npm run dev` → `http://localhost:5174`
초대 링크 테스트: `http://localhost:5174/?invite=SUMMER`

## 먼저 알아둘 용어

| 용어 | 뜻 |
| --- | --- |
| 앨범 | 여행이나 시기 하나. 사진·목소리·글이 여기에 묶인다 |
| 구성원 | 그 앨범에 참여 중인 사람. 만든 사람과 링크로 합류한 사람을 구분하지 않는다 |
| 기록 상태 | 사진 한 장 단위. `기록 중` / `기록 완료` 두 가지 |
| 초대 링크 | 앨범마다 하나. 발급일부터 7일 |
| 게스트 | 가입하지 않고 링크로 들어와 답변만 남기는 사람 |

앨범 자체에는 상태가 없습니다. 진행 정도는 사진의 기록 상태로만 나타냅니다.

## 계정

| ID | 기능 | 화면 | 사용자가 하는 일 | 규칙 | 필요한 API |
| --- | --- | --- | --- | --- | --- |
| A-01 | 소셜 로그인 | 로그인 | 구글 또는 카카오로 시작 | 신규는 약관으로, 기존은 홈으로 | `POST /auth/{provider}` |
| A-02 | 약관 동의 | 가입 1/2 | 필수 3개 체크 | 만 14세·이용약관·개인정보가 필수. 마케팅은 선택 | A-03에 같이 실어 보내도 됨 |
| A-03 | 프로필 설정 | 가입 2/2 | 이름, 캐릭터, 배경색 고르기 | 이름 없으면 다음으로 못 감 | `POST /users/me` |
| A-04 | 프로필 수정 | 내 설정 → 수정 | 이름·캐릭터·색 바꾸고 저장 | 모달에서 고른 값도 저장을 눌러야 반영 | `PATCH /users/me` |
| A-05 | 로그아웃 | 내 설정 | 로그아웃 | 가입 이력은 남는다 | 세션 만료 |
| A-06 | 회원 탈퇴 | 내 설정 → 수정 | 두 번 눌러 확인 | 다음 로그인은 신규 가입으로 시작 | `DELETE /users/me` |

## 앨범

| ID | 기능 | 화면 | 사용자가 하는 일 | 규칙 | 필요한 API |
| --- | --- | --- | --- | --- | --- |
| B-01 | 내 앨범 목록 | 홈 | 카드 누르면 상세로 | 내가 만든 앨범 + 링크로 합류한 앨범만 보인다 | `GET /albums` |
| B-02 | 앨범 만들기 | 새 앨범 만들기 | 제목·기간·설명·대표 사진 | 제목만 필수. 만들 때 초대 코드가 함께 발급된다 | `POST /albums` |
| B-03 | 앨범 정보 수정 | 앨범 정보 | 제목·기간·설명 고치기 | 구성원이면 누구나 수정. 바뀐 내용은 모두에게 보인다 | `PATCH /albums/{id}` |
| B-04 | 앨범 상세 | 앨범 상세 | 표지, 기간, 구성원, 사진·목소리 수 | 아래는 `앨범`과 `기록` 두 탭 | `GET /albums/{id}` |
| B-05 | 앨범 읽기 | 상세 → 앨범 탭 | 사진 → 글 → 목소리 순으로 쭉 읽기 | 촬영 시각 순. 글이 없는 사진은 "기록 이어가기" 버튼 | B-04 응답 재사용 |
| B-06 | 목록 정렬 | 홈 | 최근순 / 오래된 순 | 지금은 앞뒤만 뒤집는다. 수정 시각 필드가 생기면 그걸로 | `GET /albums?sort=` |
| B-07 | 앨범 삭제 | 홈 카드 메뉴 | 삭제 선택 | 확인 절차 필요. 지금은 안내만 뜬다 | `DELETE /albums/{id}` |

## 기록 (사진·목소리·글)

| ID | 기능 | 화면 | 사용자가 하는 일 | 규칙 | 필요한 API |
| --- | --- | --- | --- | --- | --- |
| C-01 | 사진 추가 | 사진 추가하기 | 여러 장 고르고 빼기 | JPG·PNG·WebP | `POST /albums/{id}/photos` |
| C-02 | 남은 사진 모아 보기 | 이어서 기록 남기기 | 기록 중인 사진만 목록으로 | 남은 장수를 상세 요약에 보여준다 | `GET /albums/{id}/photos?status=writing` |
| C-03 | AI 질문에 답하기 | 사진 기록 남기기 | 질문 3개에 목소리나 글로 답, 건너뛰기 가능 | 질문은 항상 `Q.` 로 시작 | `GET .../questions`, `POST .../answers` |
| C-04 | 목소리 녹음 | 목소리로 답하기 | 녹음·정지·다시 녹음·들어보기 | 브라우저 마이크 권한 필요 | `POST .../voices` (파일 업로드) |
| C-05 | 글 확인과 수정 | 사진 기록 | AI가 정리한 글 읽고 고치기 | 문체 3종(따뜻하게·담백하게·회고록처럼) | `PATCH .../stories/{id}` |
| C-06 | 기록 분류 보기 | 상세 → 기록 탭 | 사진 / 목소리 / 글 / 연대표 | 사진과 글은 기록 중·완료로 걸러 본다 | B-04 응답 재사용 |
| C-07 | 연대표 | 기록 → 연대표 | 시간순으로 훑고 바로 이동 | 사진 촬영 시각으로 자동 정렬 | 촬영 시각(EXIF) 저장 필요 |

## 초대와 참여

| ID | 기능 | 화면 | 사용자가 하는 일 | 규칙 | 필요한 API |
| --- | --- | --- | --- | --- | --- |
| D-01 | 참여 링크 | 초대 | 링크 복사 또는 공유 | 앨범마다 코드가 다르다. 발급일부터 7일 | `GET /albums/{id}/invite` |
| D-02 | 링크 새로 만들기 | 초대 | 만료됐을 때 재발급 | 코드가 바뀌어도 기존 구성원은 그대로 | `POST /albums/{id}/invite` |
| D-03 | 구성원 목록 | 초대 | 참여 현황 보기, 다시 초대 | 구성원이면 누구나 초대할 수 있다 | `GET /albums/{id}/members` |
| D-04 | 만들고 바로 초대 | 앨범 생성 직후 | 링크를 먼저 보고 앨범으로 이동 | 뒤로 가면 홈. 만들기 화면으로는 안 돌아간다 | - |
| D-05 | 회원이 링크로 진입 | `?invite=코드` | 자동으로 그 앨범에 합류 | 합류 후 상세로. 이미 구성원이면 그대로 | `POST /albums/{id}/join` |
| D-06 | 비회원이 링크로 진입 | 게스트 참여 | 닉네임·관계 입력 후 사진마다 답변 | 가입 없이 진행. 답변은 앨범 주인에게 전달 | `POST /albums/{id}/guest-answers` |
| D-07 | 만료된 링크로 진입 | 게스트 | 안내만 보고 닫기 | 회원·비회원 모두 막힌다 | - |
